# 接口清单

- 基地址：`http://localhost:8080`
- 请求/响应体：`application/json`（文件上传为 `multipart/form-data`）
- 鉴权：除标注「免登录」外，均需携带请求头 `Authorization: Bearer <token>`

**免登录白名单**（见 `WebMvcConfig`）：`/api/auth/login`、`/api/public/**`、`/api/certifications/by-fingerprint/**`、`/api/certifications/verify`

**通用返回码**

| 码 | 含义 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数缺失或非法（含请求体格式错误、上传超限） |
| 401 | 未登录 / token 无效 |
| 403 | 已登录但角色无权限 |
| 404 | 资源不存在（含查询未命中） |

**角色取值**：`enterprise`（企业端）、`regulator`（监管端）、`auditor`（审核端）、`admin`（系统管理员，拥有全部权限）

| GET | `/api/auth/me` | 登录 | — | 当前登录用户信息 |
| POST | `/api/auth/logout` | 登录 | — | 退出登录 |

## 2. 公共端 `/api/public`（全部免登录）

| 方法 | 路径 | 参数 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/public/enterprises` | — | 企业列表 |
| GET | `/api/public/enterprise-emissions` | — | 企业排放概览 |

## 3. 认证记录 `/api/certifications`

| 方法 | 路径 | 权限 | 参数 | 说明 |
| --- | --- | --- | --- | --- |
| GET | `/api/certifications` | 登录 | `enterpriseId`、`status`、`keyword`（均可选） | 列表 |
| GET | `/api/certifications/by-fingerprint/{fingerprint}` | 免登录 | 路径参数 | 按电子防伪码精确查询 |
| POST | `/api/certifications/verify` | 免登录 | body：`hash`（防伪码或交易哈希） | 核验，返回 `valid`/`msg`/`cert` |
| GET | `/api/certifications/{id}` | 登录 | 路径参数 | 详情 |
| POST | `/api/certifications/{id}/revoke` | regulator / admin | body：`reason`（必填）、`detail`（可选） | 撤销认证；缺 `reason` 返回 400 |

> 核验规则：防伪码精确匹配（大小写敏感）；交易哈希忽略大小写与 `0x` 前缀。核验以链上存证为准。

## 4. 排放记录 `/api/emission-records`

| 方法 | 路径 | 权限 | 参数 | 说明 |
| --- | --- | --- | --- | --- |
| GET | `/api/emission-records` | 登录 | `enterpriseId`、`period`、`sourceCode`、`status`、`keyword`（均可选） | 列表 |
| GET | `/api/emission-records/{id}` | 登录 | 路径参数 | 详情 |
| POST | `/api/emission-records` | enterprise / admin | body：`enterpriseId`、`period`、`sourceCode`、`activityData`（必填）；`enterpriseName`（可选，缺省按企业编号补全） | 新增填报，自动生成报告记录与 12 位电子防伪码 |
| DELETE | `/api/emission-records/{id}` | enterprise / admin | 路径参数 | 删除记录，并级联清理报告、认证与链上交易 |
