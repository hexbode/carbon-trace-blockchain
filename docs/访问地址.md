# 碳链通 · 访问地址速查

记录当前演示环境（WSL Ubuntu + FISCO BCOS 3.17.0 + WeBASE 3.1.1 + carbon-trace）的全部访问入口。
链本身的启停、合约升级与排障见 [联盟链使用说明.md](./联盟链使用说明.md)。

> 记录时间：2026-10-30。IP 与端口映射可能随网络环境变化，失效时按第 6 节排查。

---

## 1. 环境地址

> 仓库内不记录任何具体 IP，按下面的方法在运行时获取。

| 项 | 获取方式 |
| --- | --- |
| WSL 内网 IP | 在 WSL 内执行 `hostname -I`（形如 `172.31.x.x`，每次重启可能变化） |
| Windows 局域网 IP | Windows 执行 `ipconfig`，取当前联网网卡的 IPv4（形如 `192.168.x.x`） |
| 已有端口映射 | `8088 → 80`、`8443 → 4430` |

> 局域网访问用 Windows 的网卡 IP，不要用 WSL 的 `172.31.x.x`（那是 Hyper-V 内部网段，外部设备不可达）。

## 2. 本机访问（Windows 浏览器）

| 系统 | 地址 | 说明 |
| --- | --- | --- |
| 碳链通业务系统（HTTP） | <http://localhost:8088> | 日常入口，前端页面 |
| 碳链通业务系统（HTTPS） | <https://localhost:8443> | 自签证书；手机扫码需用这个（需信任证书） |
| 业务后端 API | <http://localhost:8080/api/> | 直连后端，跳过了 nginx |
| 后端链健康度 | <http://localhost:8080/api/blockchain/health> | 需登录 token |
| WeBASE 控制台 | <http://localhost:5000/#/login> | 账号 `admin`，密码部署时设定 |
| WeBASE-Front | <http://localhost:5002/WeBASE-Front> | 合约部署与链查询 REST 前缀 |

自签证书下载：<http://localhost:8088/carbon.crt>（装上并信任后再走 HTTPS 不再告警）。

## 3. 局域网访问（同一网段的其他设备）

| 系统 | 地址 |
| --- | --- |
| 业务系统（HTTP） | `http://<本机局域网IP>:8088` |
| 业务系统（HTTPS） | `https://<本机局域网IP>:8443` |
| 手机扫码 | `https://<本机局域网IP>:8443`（摄像头需要 HTTPS 上下文） |

WeBASE 控制台（5000）与 Front（5002）**当前未做映射**，局域网设备访问不到。需要时用管理员 PowerShell 追加：

```powershell
netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=5000 connectaddress=127.0.0.1 connectport=5000
netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=5002 connectaddress=127.0.0.1 connectport=5002
New-NetFirewallRule -DisplayName "WeBASE 5000/5002" -Direction Inbound -LocalPort 5000,5002 -Protocol TCP -Action Allow
```

> 这会把链管理入口暴露到局域网，只建议在隔离的演示网络中开启。

## 5. 常用接口速查

```bash
# 业务：公开企业列表（免登录，探活）
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8080/api/public/enterprises

# 业务：登录拿 token
TOKEN=$(curl -s -X POST http://127.0.0.1:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"regulator01","password":"123456","role":"regulator"}' | jq -r .token)

# 业务：链健康度
curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:8080/api/blockchain/health

# 链：当前区块高度
curl -s http://127.0.0.1:5002/WeBASE-Front/group0/web3/blockNumber

# 链：Front 版本
curl -s http://127.0.0.1:5002/WeBASE-Front/config/version
```

以上命令用于 WSL 内或 Windows 本机（`127.0.0.1` 在 Windows 上走 WSL 的 localhost 转发）。

## 6. 打不开时的排查顺序

1. **服务没起**：`systemctl list-units 'webase*' 'carbon-trace' --no-pager`，五个 webase 单元 + `carbon-trace` 都应是 `active (running)`；
2. **WSL IP 变了**：WSL2 重启后 IP 可能变化，执行 `wsl -d Ubuntu-26.04 -u root -- hostname -I` 确认，必要时重建 `netsh portproxy`；
3. **映射丢了**：`netsh interface portproxy show v4tov4` 应能看到 8088 / 8443 两条；
4. **防火墙拦了**：Windows 防火墙需放行对应入站端口；
5. **只在 WSL 内通**：先在 WSL 里 `curl -I http://127.0.0.1/` 确认 nginx 正常，再查 Windows 侧转发。

启停命令、合约地址与账密细节见 [联盟链使用说明.md](./联盟链使用说明.md) 第 4、6、11 节。
